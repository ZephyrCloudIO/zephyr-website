# Rspress Migration Catch-Up Plan

## Goal

Bring `feat/rspress-migration` fully up to date with `main` while preserving the Rspress SSG migration goals:

- Deploy static assets only through Rspress SSG.
- Do not introduce SSR.
- Preserve production visual parity with `https://zephyr-cloud.io`.
- Preserve SEO indexing improvements from static routes, generated metadata, canonical links, and sitemap output.
- Preserve social preview improvements from per-page Open Graph and Twitter metadata.
- Keep Zephyr plugin deployment working normally.

## Current Branch State

- Branch: `feat/rspress-migration`.
- Working tree: clean at time of recognition.
- Compared with `origin/main`: branch is ahead, but also missing newer main commits.
- Migration already replaces the Rsbuild entry with Rspress:
  - `rspress.config.ts` enables `ssg: true` and uses `withZephyr()`.
  - `docs/` is the Rspress root.
  - legacy route components are rendered through thin MDX wrappers and `RouteRenderer`.
  - `@tanstack/react-router` is shimmed by `src/router-shim.tsx`.
  - blog and changelog pages are generated by `scripts/generate-rspress-content.mjs`.
